# kiosk-project
이 프로젝트는 사용자가 다양한 메뉴 항목을 선택할 수 있는 Kiosk 프로그램입니다. 사용자는 버거, 음료, 디저트 카테고리에서 항목을 선택해서 주문할 수 있습니다.
각 메뉴 항목은 이름, 가격, 설명을 포함하고 있습니다. 또한 입력값에 따라 그에 맞는 항목과 선택한 메뉴에 대한 정보를 출력합니다. 
필수기능 1레벨부터 5레벨까지 구성되어 있습니다.

# 필수 기능 (1레벨 - 5레벨)

## 1레벨 기능
기본적인 키오스크를 구현하였습니다. 1레벨에서는 프로그램 실행시 햄버거 메뉴가 출력되며, 
`Scanner`로 숫자를 입력받아 각 메뉴 항목에 해당하는 메뉴를 선택할 수 있습니다. 
메뉴 선택은 반복문을 통해 계속해서 가능합니다. 
1~4번을 입력하면 그에 해당하는 메뉴 이름이 출력되며, 0번을 입력하면 반복문에서 빠져 나옵니다.

## 2레벨 기능
기존의 1레벨 키오스크를 클래스를 활용하여 구현하였습니다. 
`MenuItem` 클래스를 만들어 이름, 가격, 설명 등에 해당하는 멤버 변수를 갖게 하였습니다.
Main에서는 MenuItem 객체 리스트(`List<MenuItem> menuItems = new ArrayList<>();`)를 만들고, `MenuItem` 객체를 만들어 생성자를 통해 이름, 가격, 설명을 설정합니다.
이후 MenuItem 객체 리스트 에 `MenuItem` 객체들을 추가하여 
반복문을 통해 해당 리스트 안에 있는 객체의 요소에 접근하도록 하여 각 메뉴를 출력합니다.

## 3레벨 기능
기존의 2레벨 키오스크에서 Main 클래스에서 관리하던 전체 순서 제어를 이제는 Kiosk 클래스에서 관리합니다.
Kiosk 클래스에 MenuItem 리스트를 선언하여 `MenuItem`를 관리합니다.
즉, Main에서 `Kiosk` 객체가 생성될 때 생성자 매개변수를 통해 MenuItem 리스트에 값을 할당합니다. 
또한 `Kiosk` 객체 생성을 포함하여 기존에 Main에서 관리하던 입력과 반복문 로직을 Kiosk 클래스의 `start()` 메서드에서 관리합니다.
추가적으로 try - catch문을 활용하여 `InputMismatchException`, 즉 잘못된 자료형의 값을 받을 때 예외 처리를 하였고,
0~4번 이 외에 다른 번호가 입력될 경우 경고문을 출력하도록 변경하였습니다.

## 4레벨 - 5레벨 기능
4레벨 기능은 음식 메뉴와 주문 내역을 클래스로 관리하는 것이고, 5레벨 기능은 캡슐화 적용이므로 합쳐서 작성하였습니다.

### 클래스 설명

Main
- 프로그램을 시작하고 `Kiosk` 객체를 생성하여 실행합니다.

Kiosk
- 메뉴 항목을 카테고리별로 나누고, 사용자가 메뉴를 선택할 수 있도록 합니다.
- 예외 처리가 포함되어 사용자가 올바르지 않은 입력을 할 경우 경고문을 출력하고, 처음으로 돌아갑니다.

Menu
- 각 카테고리(버거, 음료, 디저트 등)의 메뉴를 관리하는 클래스입니다.
- 카테고리 이름과 해당 카테고리에 속한 메뉴 항목을 출력할 수 있는 기능을 제공합니다.

MenuItem (추상 클래스)
- 각 메뉴 항목의 공통 속성을 정의하는 클래스로, abstract로 선언합니다. 
- 메뉴 항목의 이름, 가격, 설명을 포함하고 있으며, 이를 상속받는 `Burger`, `Dessert`, `Drinks` 클래스에서 구체적으로 구현됩니다.
- `selectMenu()` 메서드는 사용자가 메뉴 번호를 선택했을 때 동적으로 해당 메뉴의 이름, 가격, 설명을 출력합니다.

Burger, Drinks, Dessert
- `MenuItem` 클래스를 상속받아 각 카테고리에 맞는 이름, 가격, 설명 등을 받아옵니다.
- 공통적으로 `selectMenu()`를 상속받아 추상 클래스의 `selectMenu()`를 호출하는 코드를 작성하였습니다. 

### 프로그램 실행 흐름

1. Main 클래스에서 `Kiosk` 객체를 생성하고 `start()` 메서드를 호출하여 프로그램을 시작합니다.

2. Kiosk 클래스의 `start()` 메서드는 사용자로부터 상위 카테고리를 선택하는 숫자를 입력받습니다.

3. 사용자가 카테고리를 선택하면, 해당 카테고리의 메뉴 항목을 선택하는 숫자를 입력받습니다.

4. 사용자가 메뉴 번호를 입력하면 선택한 메뉴 항목의 이름, 가격, 설명이 출력되며, 처음으로 돌아갑니다.

5. 2번과 3번 과정에서 잘못된 입력 값을 입력하면 예외 처리가 발생하고, 경고문과 함께 처음으로 돌아갑니다.

6. 추가적으로, 카테고리의 메뉴 항목란에서 0번을 입력하면 2번으로 돌아갑니다.
